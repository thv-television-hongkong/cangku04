# 开发与原生运行

推荐使用根目录 Docker 启动。原生调试需 JDK 17、Maven 3.9+、Node.js 18/20/22、MySQL 8；Go 1.18+ 用于链码。

仅在新建的独立 MySQL 数据库中依次导入 `database/schema.sql`、`database/views.sql`、`database/demo.sql`。基础脚本会重建表，禁止对已有个人或业务库运行。

后端开发环境通过 `SPRING_DATASOURCE_URL`、`DB_USERNAME`、`DB_PASSWORD`、`CAMPUS_JWT_SECRET` 覆盖连接和密钥；通过 `CAMPUS_IDENTITY_TEST_MODE=true` 启用测试认证。默认后端 8080，开发 profile 使用 MOCK 存证。

```bash
cd backend
mvn -DskipTests package
java -jar target/campus-charity-backend-1.0.0.jar
```

另开终端：

```bash
cd frontend
npm ci
npm run serve
```

前端默认 9528，通过开发代理访问 localhost:8080。可通过 `VUE_APP_API_TARGET` 配置代理后端地址。生产构建使用 `npm run build`，`dist` 需要 HTTP 静态服务器及 `/api` 反向代理，不能双击 index.html。

## 测试

`FinanceFlowIntegrationTest` 的 24 个集成测试固定使用**独立 MySQL 3308、空 root 测试密码、campus_charity 库**，不会访问个人运行的 3307。请仅在一次性测试环境导入上述初始化脚本后运行。备份测试需要 `mysqldump`，在 PATH 中提供，或使用环境变量 `TEST_MYSQLDUMP` 指向它。测试会写入新的独立测试业务，不能指向实际业务库。

```bash
cd backend
mvn test
cd ../chaincode
go test ./...
```

浏览器测试可安装 Playwright：`npm install --no-save playwright`、`npx playwright install chromium`。通过 `PLAYWRIGHT_MODULE` 指定模块绝对路径，或让 Node 模块解析找到 playwright。`browser-smoke.cjs` 读取 `SYSTEM_URL`；完整财务浏览器流程仅允许隔离后端 `TEST_BACKEND_PORT=8081`，并要求 `TEST_PROJECT_ID` 为测试专用项目。不要对实际业务服务执行测试数据生成脚本。

## 可选真实 Fabric

先按 `fabric-network/test-network-setup.md` 部署并核验链码。Go 链码、真实 Gateway 适配器均已包含，但未随默认容器自动部署。在 Docker 内连接外部 Fabric 时需确保 peer/orderer 主机名及 TLS hostname 可达，并将自己的证书目录只读挂载至后端。通过 `FABRIC_ENABLED=true`、`FABRIC_CERT_PATH`、`FABRIC_KEY_PATH` 等 Spring 环境变量覆盖配置。正式环境还应恢复人工认证、替换演示账号和配置通知通道。
