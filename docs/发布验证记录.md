验收脚本为 `scripts/release-smoke.py`，只应对独立演示环境运行：

```bash
python scripts/release-smoke.py --url http://localhost:9528 --allow-demo-writes
```

该脚本会创建虚构测试账号和业务记录，不清理历史记录；请勿指向实际业务系统。当前工作电脑未安装 Docker，容器启动仍需要在 Docker 环境验收。GitHub Actions 包含从空库构建和启动容器的验证流程，状态以实际运行结果为准。原生测试通过不代表已经验证容器运行。真实 Fabric 网络亦未在本机部署验收。
