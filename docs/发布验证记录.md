验收脚本为 `scripts/release-smoke.py`，只应对独立演示环境运行：

```bash
python scripts/release-smoke.py --url http://localhost:9528 --allow-demo-writes
```

该脚本会创建虚构测试账号和业务记录，不清理历史记录；请勿指向实际业务系统。
